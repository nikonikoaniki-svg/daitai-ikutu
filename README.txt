漢字輪郭カード　アプリ試作版 v1.0

使い方
1. index.html をダブルクリックしてブラウザで開きます。
2. 学年・カードの種類・学習方法を選び、「10まい はじめる」を押します。
3. 漢字を声に出して読み、答えを見て、読めたかどうかを記録します。
4. まず輪郭イラストつきで練習し、読めたカードは次回から絵なしで出題。
5. 絵なしで2回読めたカードは「できた！」として記録されます。

機能
・1〜4年の選定カード、おまけの難読動物漢字、熟語
・元画像を直接流用しないオリジナルSVG輪郭イラスト
・自動で絵のヒントが消える練習・最初から絵なし等を選択
・4択と音読自己評価の2モード（4択は絵なし達成にカウントしない）
・日本語音声（ブラウザ/OSが対応する場合）
・学習履歴をブラウザ内に保存、CSV出力
・先生用画面でカード1枚ずつ追加、CSV一括登録、画像追加
・インターネット接続不要（1つのHTMLで動作）

留意点
・教材内容は試作版です。小1〜小4の642字すべては未収録です。
・絵をつけやすい名詞を中心に選び、一部のカードには輪郭イラストがありません。
・手動評価は本人の自己申告です。教育的なアセスメントとしては、教師による確認が必要です。
・進捗は同じブラウザ内だけに保存されます。共有端末では児童別の利用を工夫してください。
・音声再生はブラウザの音声合成機能に依存します。
・SVG輪郭線は新たに作成したオリジナルです。既存の輪郭漢字カード画像は埋め込んでいません。
・漢字の学年は出題例とともに別途教師による校閲を推奨します。

CSV形式
学年,種類,漢字,読み,イラスト
1,一文字,耳,みみ,ear
2,熟語,金魚,きんぎょ,fish

※ web公開する場合は、index.htmlを静的ホスティングに配置してください。
